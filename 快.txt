运行
# 1. 定义自定义算法（示例：冒泡排序）
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

# 2. 在项目中添加/调用该算法
if __name__ == "__main__":
    data = [3, 1, 4, 1, 5, 9]
    sorted_data = bubble_sort(data)
    print("自定义冒泡排序结果：", sorted_data)  # 输出 [1, 1, 3, 4, 5, 9]

Python 最常用核心库（分场景整理，高频必学）
✅ 按使用频率 + 重要程度排序，零基础优先学标注「★★★」的，够用 90% 开发场景，无冗余内容，手机友好版。
一、【基础必备】Python 内置 + 必装通用库（人人必学）
不用额外学，Python 自带 / 装了就能用，所有方向通用
内置库（无需 pip 安装）：os(文件路径 / 系统操作)、sys(系统参数)、math(数学计算)、random(随机数)、datetime(时间日期)、json/csv(数据格式解析)、re(正则表达式)
★★★ requests：爬虫 / 接口请求天花板，极简调用，爬网页、调 API 必备
★★★ numpy：数值计算核心库，矩阵 / 数组运算，速度极快，所有数据类方向的基础
★★★ pandas：数据分析王者，表格数据处理 / 清洗 / 筛选 / 统计，Excel 平替，数据分析 / 机器学习必学
★★★ matplotlib / seaborn：绘图可视化，画折线图 / 柱状图 / 热力图，pandas 无缝衔接，做图表必备
二、【分方向】高频常用库（按需学习，优先级高）
✅ 数据科学 / 机器学习 / 人工智能（最热门）
进阶计算 / 可视化：scipy(科学计算，积分 / 拟合 / 线性代数)、plotly(交互式动态图表，比 matplotlib 好看)
★★★ scikit-learn：机器学习入门天花板，封装了所有经典算法（回归 / 分类 / 聚类 / 降维），开箱即用，不用手写算法
keras / tensorflow：深度学习主流框架，做神经网络、图像识别、NLP，入门首选 keras（tf 封装的高阶 API）
pytorch：深度学习第二主流框架，学术界 / 大厂更常用，灵活性高，和 numpy 兼容极好
opencv-python：计算机视觉，图像处理、人脸检测、视频识别
jieba：中文分词，NLP（自然语言处理）基础库，处理中文文本必备
✅ 爬虫 / 自动化（易上手，刚需）
★★★ BeautifulSoup4：解析网页 HTML/XML，提取网页内容，搭配 requests 无敌
lxml：网页解析，速度比 bs4 快，支持 xpath 语法，爬虫进阶用
selenium：浏览器自动化，模拟人工点击 / 输入，爬动态加载网页（js 渲染）必备
playwright：新一代自动化库，比 selenium 好用，自动处理弹窗 / 登录，微软出品，推荐优先学
aiohttp：异步请求库，爬虫提速神器，爬大量数据时用，效率翻倍
jsonpath / pyquery：解析 json/jsonp 数据、网页 css 选择器提取内容
✅ 后端开发 / 接口开发
★★★ flask：轻量级 web 框架，极简入门，写接口、小网站、后端服务首选，学习成本极低
★★★ django：重量级全能 web 框架，自带 admin 后台 / 数据库 ORM / 用户认证，适合开发中大型网站 / 系统
fastapi：新一代高性能接口框架，支持异步，自动生成接口文档，现在最火的后端库之一，强烈推荐
uvicorn：搭配 fastapi 的异步服务器，部署必备
pymysql / psycopg2：python 连接 MySQL/PostgreSQL 数据库
redis-py：连接 redis 缓存数据库
sqlalchemy：数据库 ORM 框架，不用写原生 SQL，适配所有数据库
✅ 办公自动化 / 脚本工具（职场刚需，提效神器）
★★★ openpyxl / xlrd/xlwt：操作 Excel 表格，读写数据、修改格式，职场必学
python-docx：操作 Word 文档，生成报告、批量修改内容
python-pptx：操作 PPT，批量生成幻灯片
pdfplumber / PyPDF2：读取 / 分割 / 合并 PDF 文件，提取 PDF 文本
win32com：调用 Windows 系统组件，实现 Excel/Word 宏、邮件发送、桌面操作
schedule：定时任务库，极简实现「定时执行脚本」（比如每天 8 点自动发报表）
✅ 其他高频刚需库（全场景通用）
★★★ pypdf2 / pdfplumber：PDF 处理
pillow(PIL)：图像处理，裁剪 / 加水印 / 调色 / 生成验证码，简单好用
logging：日志库，替代 print，项目调试 / 上线后排查问题必备
argparse：命令行参数解析，写可配置的脚本必备
tqdm：给循环加进度条，跑批量任务时看进度，超实用
pyyaml：解析 yaml 配置文件，项目开发中管理配置必备
三、【避坑指南】库的安装方式（统一通用）

python
